# Code of Conduct

## Our commitment

We want AYORAI AI Shield to be a constructive technical environment for contributors with different backgrounds and levels of experience.

## Expected behavior

- Be respectful and professional.
- Focus criticism on technical ideas, code, evidence, and behavior.
- Provide actionable feedback.
- Welcome questions and good-faith disagreement.
- Protect confidential and sensitive information.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberate disruption of project infrastructure.
- Malicious or unsafe use of project resources.

## Maintainer response

Project maintainers may remove comments, close issues, or restrict participation when conduct violates these expectations.

## Scope

This code applies to project spaces and interactions related to the repository, including issues, pull requests, reviews, and discussions.
