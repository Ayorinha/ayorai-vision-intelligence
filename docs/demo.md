# Demo

Use only public or synthetic video.

1. Start the API.
2. Load the synthetic knowledge:
   python scripts/seed_demo.py
3. Open the Streamlit dashboard.
4. Upload a demo video.
5. Follow the job state.
6. Inspect detections and low-confidence reviews.
7. Approve or reject a review.
8. Query the evidence-first agent.
9. Inspect available tool calls.

The repository does not ship proprietary or regulated video.
