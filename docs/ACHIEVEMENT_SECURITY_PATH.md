# Legitimate GitHub security-recognition path

The AI Shield project strengthens the security engineering portfolio, but it does **not** manufacture a GitHub security achievement. GitHub documents the Security Bug Bounty Hunter badge for people who help identify security vulnerabilities, and Security advisory credit for accepted advisories.

## Real path

1. Keep AI Shield public, tested and reproducible.
2. Contribute meaningful security fixes to established open-source projects.
3. Use private/coordinated disclosure when a genuine vulnerability is found.
4. Never test against systems without authorization.
5. Preserve evidence, minimal reproduction, impact and remediation.
6. Seek maintainer credit when appropriate.
7. Build a public record of merged security fixes and reviews.

The objective is security contribution, not badge farming. No synthetic vulnerability or self-issued advisory should be used to claim a security achievement.
